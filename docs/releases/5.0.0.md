# Ars Instrumentum 5.0.0 (NeoForge 1.21.1)

First release of this fork's NeoForge 1.21.1 line, based on upstream Ars Instrumentum `1.21.x`.

- Runs on Minecraft 1.21.1 with NeoForge 21.1.265 or later 21.1 and Java 21.
- Supports the Evil Eye pack's Ars Nouveau 1.21.1-5.13.3 baseline.
- Preserves the established `ars_instrumentum` mod id and the 4.1.0 item, block, block-entity, recipe, and data identifiers used by existing worlds.
- Adapts networking, components, recipes, Curios integration, rendering, and generated data to the NeoForge 1.21.1 APIs.

Upstream authorship and the GNU LGPL v3.0 license are retained. Fork provenance and the installed-pack compatibility baseline are recorded in `docs/UPSTREAM.md` and `.ci/port-provenance.json`.
